# CLARKTHESISCODE

This code supports the spatial and temporal analyses of white shrimp in Lydia Clark's master's thesis. AI was consulted for error codes and model structure, and the author thoroughly checked and corrected any AI-produced code before implementation. The author provided three out of the four data files used for the analysis, the fourth could not be uploaded as the file was too large. The fourth file was titled MDNR_CBFI data (1990-2012). Results and discussion used in the defense were based on model results.
